# 幻想防线：模块化视觉框架

本次继承 `01-brief-design.md` 和 `02-architecture.md` 的玩法与技术边界；这是表现层升级，不是战斗规则重做。

## 视觉方向

目标是轻松但有守城史诗感的幻想塔防。暖金代表可执行操作与奖励，森林绿承载环境，浅沙色道路优先于背景细节。主界面只保留开始冒险、创意工坊两个核心入口，设置在右上角。

大厅由天空、山体、河流、云、城堡、塔、旗帜、火焰、粒子独立组合。世界封面复用场景组件，但语义主题会选择森林、水晶或裂隙的地貌、主物件和配色；浮岛关键词另启用云上城堡与卫星岛构图，不导入模型给出的图片地址。世界卡显示实际关卡难度、存档进度和已保存的敌人主题名称。

大厅新增实际已完成关卡/总关卡、全部通关世界数和固定可用塔数；没有玩家等级、假奖励或模拟挑战数据。绘本纸纹、标题纹章和低对比飞鸟为独立装饰层；减少动态设置仍生效。

战场按地形 → 道路 → 固定建造位 → 按落地点排序的建筑/怪物 → 弹道 → 状态提示分层。道路来自 MapSpec 连通关系，不从图片猜测。环境物件避开道路、塔位与出入口。移动端使用完整视口，保留底部建造栏和顶部生命/金币/波次；触摸在最近合法塔位周围提供 22px 容错。

## 关键反馈

- 部署：塔位＋号、选中描边、金币变化与短暂落地动画。
- 选塔时在原提示区显示配置中的伤害、射程、攻速和功能定位，不增加常驻 HUD 面板；资金不足的塔仍可选中查看。重复点击同种塔取消选择。
- 鼠标悬停显示可建造/金币不足/非建造位文字及绿红区域；射程按核心使用的欧氏距离采样后进行等距投影，不用任意缩放椭圆冒充真实范围。
- 战场的河流、以太通道、裂隙与桥面只改变渲染。装饰河道优先选择少塔位、少道路交叉的列；受保护塔位仍会跳过，不移动任何地图逻辑对象。
- 开波：入口脉冲、波次横幅、怪物独立行走帧。
- 命中/击杀：闪白、弹道、局部粒子与奖励飘字。
- 升级：由 core 的 towerUpgraded 事件触发星芒与等级文字。
- 漏怪：生命数值、城堡受击与提示；暂停冻结表现时间线。
- 系统低动态偏好和游戏内设置均关闭装饰运动，保留文字、血条与静态状态。

## 资源协议

`assets/library/ASSET_MANIFEST.json` 是授权和本地路径的唯一清单。
`assets/library/realm/runtime/` 是筛选后的 54 个独立 PNG；不加载下载包、整张关卡背景或外部图片。
`fantasy-asset-config.ts` 控制固定角色与素材的映射、显示比例、敌人动画帧数和时长。
`world-asset-registry.ts` 复用现有落地点/深度合同；未匹配主题采用统一幻想资源族。将来添加皮肤应在受控映射中扩展，不接受 AI URL。

素材来源由 Asset MCP 与 OpenGameArt 搜索确认。具体作者、许可证和加工过程见 `assets/library/realm/CREDITS.md`，游戏设置内也展示 CraftPix 署名。
导入脚本只作开发工具；通过 Sharp 规范透明边距、合成塔身与冠部并抽取固定步行帧，不进入客户端或服务器运行流程。

## 完成度边界

已建立可替换/缩放/动画的视觉框架，并非宣称商业发行验收完成。当前获授权素材的城堡、低多边形植被与描边塔/敌人仍有风格差异，下一轮需要同一美术方向的专用城堡与植被资源。封面现在有四种构图变体，但同类语义世界仍会共享对应的受控资源族；不为每个世界生成独占图片。无新增音频、原创全套动画或真机性能结论。

AI 创作、地图模板验证、四种塔/四种敌人、Simulator 和 Metrics 保持原有约束。已有世界游玩不调用 LLM；当前 UI 沿用生成/评测工作区，未新增社区市场功能。
